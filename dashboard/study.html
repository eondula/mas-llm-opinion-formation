Agent-negotiated closure uses a separate proposal and confirmation phase after each update round. All agents must accept the same proposal; disagreement may remain. With No peer, no closure messages are exchanged and the round limit applies. All controls remain available. Fixed-list arguments restrict what agents can express. No peer is a control with no exchange; matching choices alone do not demonstrate collaboration.

After each complete update round, stops when every agent keeps its strategy, message cosine similarity is at least 0.8, and its post-response margin stays on the same side of zero (zero counts as positive). No minimum rounds. The maximum remains a safeguard.

Each repetition starts with fresh agent histories. Sampled runs use distinct saved seeds; greedy repeats may be identical.

Forced answers apply only at round 0. Agents can revise afterward. Shared models with greedy decoding can produce similar responses; sampling uses reproducible per-agent seeds.

The model generates a strategy and explanation. Stance is measured separately. Forced initialization still assigns round 0. Uses the combined reasoning prompt.

Open and Topic discussion use Combined prompt (flexible reasoning). Topic discussion supplies only the topic and two strategies, without scenario properties, context paragraphs, or argument lists. After receiving peer messages, agents are instructed to address a specific point and name the agent who made it. Original, Open and Topic discussion select scored choices before the response. Discussion then decision reassesses after discussing each update; initialization stays choice first. It uses the scenario context and supplied arguments.
